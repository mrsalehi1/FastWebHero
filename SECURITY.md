# Security policy

## Supported versions

Security fixes are applied to the latest code on `main`. The project does not yet publish versioned releases.

## Report a vulnerability

Do not open a public issue for a suspected vulnerability.

Use [GitHub private vulnerability reporting](https://github.com/mrsalehi1/FastWebHero/security/advisories/new) and include:

- the affected command or component;
- steps to reproduce the problem;
- the potential impact;
- any suggested mitigation.

Do not include real AWS credentials or other secrets. You should receive an acknowledgement within seven days. Details should remain private until a fix is available.
