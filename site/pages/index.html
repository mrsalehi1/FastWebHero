Static website

Write the pages. Publish them to S3.

This starter turns HTML, CSS, and a shared layout into a static site, then uploads that site to an S3 bucket configured for website hosting.

How the build works Contact

From folder to website

Three commands cover the whole path from a page edit to a public URL.

  1. Edit

    Pages live in site/pages. The shared header and footer live in site/layouts.

  2. Build

    npm run build renders every page into the dist folder.

  3. Publish

    npm run publish uploads dist and turns on S3 static website hosting.

What you change

Rename the site in site/site.json, then replace these sample pages with your own. Styles and images are copied through as static files.

site/pages
One HTML file for each page.
site/layouts
The document that wraps every page.
site/public
Files copied to the site root, such as the icon.
dist
The finished site that gets uploaded.
