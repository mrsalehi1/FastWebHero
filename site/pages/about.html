--- title: About description: How this TypeScript project builds a static site and hosts it on S3. ---

About

A small builder with a plain output.

The TypeScript app reads this folder, fills in the layout, and writes normal HTML. After publish, S3 is the web server.

Pages

Each file in site/pages is a fragment, not a full document. A short header at the top sets the title and description. The file name becomes the URL: about.html is served at /about/.

Layout

site/layouts/default.html holds the parts that repeat: the document head, navigation, and footer. The builder replaces {{content}} with the page, and {{nav}} with the links from site/site.json.

Hosting

Deploy uploads every file in dist, sets the index and error documents, and adds a bucket policy so visitors can read the objects. Use a bucket that is only for this site. The S3 website endpoint is HTTP. Put CloudFront in front of it when the site needs HTTPS.
